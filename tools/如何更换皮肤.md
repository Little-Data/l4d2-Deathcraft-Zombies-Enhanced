0. 先弄懂三件事
----------------------------------------------------------------------
(1) 游戏里"僵尸长什么样"是三层关系：

      population*.txt   ——  决定这张地图刷哪些模型、各占多少 %
            ↓
      common_xxx.mdl    ——  模型（形状 + 内部记着一个"材质名"）
            ↓
      common_xxx.vmt    ——  材质（指向一张贴图）
            ↓
      xxx.vtf           ——  真正的皮肤图片

    **换皮肤 = 改模型里那个"材质名"，模型形状不变。**
    **加新外观 = 复制一个模型 + 给它新材质名 + 把这个新模型写进刷新表。**

(2) 一个皮肤文件可以被多个模型共用；一个模型同一时间只用一个皮肤。

(3) 改完文件夹里的东西，**必须重新 pack 成 VPK** 才会进游戏。


1. 准备环境
----------------------------------------------------------------------
安装 Python 3（安装时勾选 Add python to PATH），然后：

    pip install pillow numpy

`skin_tool.py` 是单文件、独立的工具：VTF 编解码、VPK 打包/解包、预览渲染都在
它自己里面，不需要、也不会调用任何其它工具。

之后在 `skin_tool.py` 所在目录执行：

    cd <skin_tool.py 所在目录>

默认操作同级目录下的 `Deathcraft Zombies Enhanced` 文件夹，放在别处时加
`--mod "路径"`。


2. 场景 A：把某只僵尸换成另一张"已有"皮肤
----------------------------------------------------------------------
例：让 common_male01 穿 shirt5zom（花衬衫）。

第一步，看现在有哪些模型、哪些皮肤：

    python skin_tool.py list
    python skin_tool.py skins

第二步，换：

    python skin_tool.py assign common_male01 shirt5zom

输出 `common_male01: blockdude -> shirt5zom` 就成功。

第三步，看看效果（可选，会生成一张渲染图）：

    python skin_tool.py preview common_male01

第四步，打包（见第 7 节）。

> 想撤销：再 assign 回原来的皮肤即可（`list` 里能看到原名）。


3. 场景 B：改一张现有皮肤的画面（保持名字）
----------------------------------------------------------------------
适合"这张皮肤颜色我想调一下""眼睛想改一改"，**模型不用动**。

第一步，导出 PNG：

    python skin_tool.py vtf2png shirt5zom  D:\work\shirt5zom.png

第二步，用 Photoshop / Aseprite / paint.net 改图（保持 64×32 布局，见第 9 节）。

第三步，导回（名字必须一样，会覆盖）：

    python skin_tool.py png2vtf D:\work\shirt5zom.png shirt5zom

第四步，打包。

> 注意：`png2vtf` 会自动把它放大到 512 宽再压 DXT5，这是正常的，
> 原图仍然用 64×32 画就行。
> 如果文件名里有空格（例如 `armour leat.vtf`），命令里要加引号：
>     python skin_tool.py png2vtf "D:\work\armour leat.png" "armour leat"


4. 场景 C：做一张全新皮肤，给某只僵尸用
----------------------------------------------------------------------
第一步，画一张 64×32 的 Minecraft 皮肤（或网上找一张），例如 `my_zombie.png`。

第二步，导入 mod（自动生成 vtf + vmt）：

    python skin_tool.py newskin D:\work\my_zombie.png my_zombie

第三步，挂到模型上：

    python skin_tool.py assign common_male_tanktop_overalls my_zombie

第四步，`python skin_tool.py preview common_male_tanktop_overalls` 看一下，
满意就打包。


5. 场景 D：做全新皮肤 + 新增一个"变体"（带刷新概率）
----------------------------------------------------------------------
想要"同一个外观的僵尸，偶尔出现另一种皮肤"，就用变体：
复制一个现成模型，换皮，再给它一个小的刷新概率。

第一步，导入新皮肤（同场景 C）。

第二步，复制模型做变体：

    python skin_tool.py copy-model common_male_tshirt_cargos common_male_tshirt_cargos_v2 my_zombie --weight 5

   * 第 1 个参数：复制谁（源模型，建议选"外观/体型一致"的）
   * 第 2 个参数：新模型名（随意，建议加后缀 _v2/_alt）
   * 第 3 个参数：新模型用的皮肤
   * `--weight 5`：在刷新表里占 5%（只在源模型原本出现的区域里加）

第三步，`python skin_tool.py list` 确认新模型存在，`preview` 看一下。

第四步，打包。

> **头盔问题**：模型分两种
>   * 264 顶点（45 个）：没有头盔箱，头顶就是普通方块
>   * 288 顶点（24 个）+ 432 顶点（1 个 military_male01）：带头盔箱，
>     皮肤上的"帽子层"会显示成头盔
> 所以带护甲/头盔的皮肤要复制 288 的模型，普通皮肤复制 264 的模型，
> 否则头盔会不显示（或普通皮肤出现一个奇怪的方块）。
>
> 264 顶点：female01 / female01_suit / female_* / male01 / male_ceda* /
>   male_dressshirt_jeans* / male_fallen_survivor* / male_formal / male_jimmy /
>   male_parachutist / male_polo_jeans* / male_roadcrew_rain / male_rural01* /
>   male_suit / male_tanktop_jeans* / male_tanktop_overalls* / male_tshirt_cargos* /
>   patient_male01* / surgeon_male01
> 288 顶点：male02* / male_baggagehandler_01,02 / male_biker* / male_clown /
>   male_mud* / male_pilot* / male_riot* / male_roadcrew* / military_gold /
>   police_chain / police_male01 / tsaagent_male01 / worker_male01*


6. 场景 E：调刷新概率 / 让某只僵尸不再出现
----------------------------------------------------------------------
刷新表在 `Deathcraft Zombies Enhanced\scripts\` 下，6 个文件：
`population.txt`（主要）、`population_l4d1coop.txt`、`population_l4d1survival.txt`、
`population_l4d1vs.txt`、`population_survival.txt`、`population_versus.txt`。

格式（每段百分比必须合计 100）：

    Population
    {
        default                       <- 区域名（对应地图的 nav place name）
        {
            common_male_tshirt_cargos   30
            common_male_tanktop_jeans   20
            ...
        }
    }

- **调高/调低某只僵尸**：直接改数字，同段其它数字相应加减，保持 100。
- **让它不再出现**：把那一行删掉，并把少掉的百分比分给别的行。
- 改完 `python skin_tool.py check` 会检查每段是否 100、有没有写错的模型名。

> 提示：特殊感染者（防暴 riot、CEDA、小丑、Jimmy、溺尸 mud、被感染生还者）
> 建议保持低百分比（2~10%），这样既稀有又能认出来。


6.5 批量导入 / 导出皮肤
----------------------------------------------------------------------
**一次导入整个文件夹**（递归读取 png / tga / bmp / jpg / webp / gif）：

    python skin_tool.py batch D:\我的皮肤

- 不给输出目录：直接写进 mod 的材质目录；
- 给输出目录：在它下面生成**标准 materials 结构**，可直接打包或复制进 mod：

      <输出根目录>\
      └─ materials\models\infected\zombie\
         ├─ 皮肤A.vtf
         ├─ 皮肤A.vmt
         ├─ 皮肤B.vtf
         └─ 皮肤B.vmt

- 文件名就是皮肤名；中文/特殊字符会被替换成安全名，替换结果写在同一目录的
  `_renamed.txt`；重名自动加 `_2`、`_3`。
- 常用选项：
    `--overwrite`  覆盖已存在文件
    `--dry-run`    只列出将要做的事，不写盘
    `--no-vmt`     不生成 .vmt
    `--flat`       不建 materials 目录，直接写进输出目录
    `--size 512`   最小宽度
    `--format dxt5|dxt1|auto`
    `--no-recursive` 只处理顶层文件

**一次导出全部皮肤**（用于备份或批量改图）：

    python skin_tool.py export D:\皮肤备份
    python skin_tool.py export D:\皮肤备份 --used-only   （只导出有模型在用的）

> 批量导入的皮肤**不会自动挂到模型上**，`check` 会提示 "skin xxx is not used"。
> 一次挂完用 `attach`（见下），单独挂用 `assign` / `copy-model`。

**把没挂上的皮肤一次性挂到模型上：**

    python skin_tool.py attach                    # 所有未使用皮肤 → 各建一个变体
    python skin_tool.py attach --weight 6         # 刷出概率 6%（默认 4）
    python skin_tool.py attach --replace          # 直接替换基础模型的皮肤，不建变体
    python skin_tool.py attach 皮肤A 皮肤B         # 只挂指定的皮肤
    python skin_tool.py attach --dry-run          # 先看计划，不写盘

- 皮肤的“右上角头盔层”如果有内容 → 复制 288 顶点模型（会显示头盔）；
  否则复制 264 顶点模型。
- 基础模型按“刷新表里出现最多的”顺序轮换，变体多数地图都能刷到；
  并自动写进 `population*.txt`。
- `--replace` 会把基础模型原来的皮肤换掉，旧皮肤就变成“未使用”，
  `check` 会提醒——适合“用新图替换旧图”的场景。


7. 打包并安装
----------------------------------------------------------------------
    python skin_tool.py check          <- 自检（强烈建议）
    python skin_tool.py pack           <- 生成 ..\Deathcraft Zombies Enhanced.vpk
    python skin_tool.py install "E:\Software\Steam\steamapps\common\Left 4 Dead 2\left4dead2\addons"

进游戏即可。**不要和其它替换普通感染者的 mod 同时启用。**


8. 自检与排错
----------------------------------------------------------------------
`check` 会检查：
  * 每个模型的 .vmt / .vtf 是否存在
  * .mdl 头部 length 是否和文件大小一致（改坏会报）
  * 特殊皮肤有没有串到普通模型
  * 有没有皮肤完全没被使用（会提示，不一定是错）
  * 有没有 .phy（必须没有）
  * population 每段是否 100、模型名是否存在

| 现象 | 处理 |
|---|---|
| 游戏里完全没变化 | 忘了 pack / VPK 没进 addons / 同时开了别的普通感染者 mod |
| 模型发紫黑 | 材质名写错，或 .vmt 里 $basetexture 指向不存在的图 |
| 只有一部分僵尸变了 | 该模型不在刷新表里，或那张地图用的是别的 section |
| 头顶多出一个方块 / 头盔不见了 | 皮肤和模型的顶点数不匹配（264 vs 288，见场景 D） |
| 尸体布娃娃扭曲 | mod 里混进了 .phy，删掉（check 会提醒） |
| 中文乱码 | 工具输出故意用英文；文件内容（txt/csv）用 UTF-8 保存即可 |


9. 皮肤绘制要点
----------------------------------------------------------------------
* **尺寸**：64×32（经典 Minecraft）。也支持 128×64 / 256×128 / 512×256，
  工具会自动整数倍放大到 512 宽。
* **布局**：标准 64×32 皮肤布局：
  - 左上 (0,0)-(32,16)：头部六个面
  - 头正面 (8,8)-(16,16)：**眼睛在这个区域**
  - 身体 (16,16)-(40,32)
  - 右臂 (40,16)-(56,32)
  - 右腿 (0,16)-(16,32)
  - 右上 (32,0)-(64,16)：帽子/头盔层（只有 288 顶点模型会显示）
* **不要自己改 UV**：所有模型共用一套标准 UV，改了贴图布局就会错位。
* **透明**：可用（材质开了 $alphatest），但大面积透明会看到模型内部。
* **眼睛**：如果人物看起来"没有脸"，通常是头正面那块没画眼睛。
* **不要用照片素材直接缩到 64×32**：会糊，建议先用像素画风格处理。


10. 命令速查表
----------------------------------------------------------------------
    python skin_tool.py list                          列出模型 → 皮肤
    python skin_tool.py list --special                只列特殊变体
    python skin_tool.py skins                         列出全部皮肤与尺寸
    python skin_tool.py vtf2png <皮肤名> [out.png]    皮肤导出 PNG
    python skin_tool.py newskin <图片> <皮肤名>       图片导入成 VTF+VMT
    python skin_tool.py png2vtf <图片> <皮肤名>       同上
    python skin_tool.py batch <图片目录> [输出根目录]  批量导入，输出标准 materials 结构
    python skin_tool.py export [目录] [--used-only]    批量导出全部皮肤 PNG
    python skin_tool.py attach [皮肤...] [--weight 4] [--replace]
                                                      把所有未挂上的皮肤批量挂到模型
    python skin_tool.py assign <模型> <皮肤名>        换模型用的皮肤
    python skin_tool.py copy-model <源> <新> <皮肤> [--weight 4]
                                                      复制模型做变体并进刷新表
    python skin_tool.py preview <模型> [out.png]      渲染预览图
    python skin_tool.py check                         自检
    python skin_tool.py pack [out.vpk]                打包
    python skin_tool.py install <addons目录>          复制 VPK 进游戏
    python skin_tool.py extract <vpk> [目录]          解包查看

所有命令都可以在最后加 `--mod "另一个 mod 目录"`（也可以写在命令前面）。


11. 备份与还原
----------------------------------------------------------------------
> 两个原始素材文件夹（Deathcraft Zombies[fix]、Minecraft Zombies Fix Fixed Again）
> 之后会被删除，**不要依赖它们**。备份只靠自己做的存档。

* **最稳的备份**：整个复制一份 `Deathcraft Zombies Enhanced` 文件夹（改之前做）。
* **轻量备份**：把皮肤全部导出成 PNG，体积小、可直接改：

      python skin_tool.py export D:\皮肤备份
      python skin_tool.py export D:\皮肤备份 --used-only

  还原时批量导回：

      python skin_tool.py batch D:\皮肤备份

* 还原单个模型：`assign` 回原来的皮肤（`list` 能查到原名）。
* 还原单张皮肤：`vtf2png` 有导出过就用 PNG 导回；没有就只能用文件夹备份覆盖。
* 还原全部：删掉现在的 mod 文件夹，用文件夹备份覆盖。
